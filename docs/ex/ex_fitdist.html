Assign uncertainty to parameters

In the examples above you use estimate parameters using maximum likelihood. This provides a point estimate. In the diclofenac, where the fitted probability distribution represents variability between sites, you want to have uncertainty in parameters as well. Thereare several options to fit distributions and get uncertainty in parameters.

If done in Bayesian framework, parameters would have been estimated with probability distributions. You are not expected to be able to do that in this course. To get uncertainty outside a Bayesian framework, one can use bootstrap. An alternative way is to using the information from the maximum likelihood estimation and assign a distribution based on that.

  • Bayesian - best but not required for this course

  • Bootstrap - a good alternative when there is enough data for resampling, captures correlation between parameters. Contact Ullrika if you want to do this

  • Assign distribution in parameters using ML estimation info. This approach is described below.

Using ML estimation info

In fitdist you get the standard deviation of the estimated parameter. I suggest you use this to construct a probability distribution for the parameters. This is an ‘ad hoc’ method, but it is sufficient for the project.

fit4 <- fitdist(x,distr= "lnorm", method = "mle")

For the lognormal distribution we have two parameters (mean and sd on the log scale).

fit4$estimate # the estimated values (central)
  meanlog     sdlog 
-3.135851  2.202322 
fit4$sd # the standard deviation in the estimated values
  meanlog     sdlog 
0.4924541 0.3482173

We can use the normal distribution to represent uncertainty on the meanlog

meanlog_mean = fit4$estimate[1]
meanlog_sd = fit4$sd[1]

# random draw from the parameter distribution
rlnorm(1,meanlog_mean,meanlog_sd)
[1] 0.05342969

We can use a uniform distribution to represent uncertainty on the sdlog

sdlog_mean = fit4$estimate[2]
sdlog_sd = fit4$sd[2]


# random draw from the parameter distribution
runif(1,max(sdlog_mean-sdlog_sd,0),sdlog_mean+sdlog_sd)
[1] 2.066226

In case you work with a gamma distribution, consider that it has two parameters (shape and rate).

# Example with gamma
fit3 <- fitdist(x,distr= "gamma", method = "mle")
fit3$estimate # the estimated values (central)
    shape      rate 
0.4127028 1.9434447 
fit3$sd # the standard deviation in the estimated values
    shape      rate 
0.1058674 0.8403148

These two parameter values are both strictly positive. if we select a probability distribution for them, we have to ensure that they are positive and not zero.

I suggest you describe uncertainty in these parameters using a probability distribution that is strictly positive as well. In the code below I use a lognormal distribution. First I transform the mean and sd of the estimated parameter to logscale and then put these into the lognormal distribution.

shape_mean = fit3$estimate[1]
shape_sd = fit3$sd[1]

shape_sigma = sqrt(log(1+(shape_sd/shape_mean)^2))
shape_mu=log(shape_mean)-shape_sigma^2/2

# random draw from the parameter distribution
rlnorm(1,shape_mu,shape_sigma)
[1] 0.5414673
rate_mean = fit3$estimate[2]
rate_sd = fit3$sd[2]

rate_sigma = sqrt(log(1+(rate_sd/rate_mean)^2))
rate_mu=log(rate_mean)-rate_sigma^2/2

# random draw from the parameter distribution
rlnorm(1,rate_mu,rate_sigma)
[1] 1.549783

Calculate probability a random variable is greater than a fixed value

Let us say that X follows a distribution

To calculate the probability that X is greater than a value \(x_0\), i.e. \(P(X>x_0)\) one use the probability function for the complementary event.

\[P(X>x_0) = 1-P(X\leq x_0)\]

# example with normal distribution
mean=3
sd=1
x0 = 2
1-pnorm(x0,mean,sd)
[1] 0.8413447
